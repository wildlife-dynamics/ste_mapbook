STE Mapbook Workflow

Generates a multi-section mapbook report for wildlife tracking data sourced from EarthRanger. For each subject, the workflow produces six map visualizations, a Word document report, and an interactive dashboard.

Step-by-step instructions for configuring and running the workflow, with screenshots.

Common errors you may hit while configuring or running the workflow, and how to resolve them.

What it produces

OutputDescription
Movement Tracks mapCurrent vs. previous period tracks, color-coded by period
Speed MapTrajectories colored by speed bins (km/h)
Day/Night MapTrajectories colored by day (orange) or night (dark blue)
Home Range mapElliptical Time Density (ETD) contours + Minimum Convex Polygon (MCP)
Mean Speed RasterHexagonal raster of mean movement speed
Seasonal Home RangeETD contours split by wet/dry season
Mapbook (.docx)Word document with a cover page and one section per subject
DashboardInteractive widget dashboard with all maps and summary metrics

Requirements

  • Access to an EarthRanger instance with a configured data source
  • Access to a Google Earth Engine project
  • The landDx geodatabase (downloaded automatically from Dropbox by default)

Get started

New to the workflow? Start with the User Guide for a walkthrough of adding the template, configuring connections, and setting parameters. Running into an error? Check Troubleshooting first.
